Password Suppression Test

How to test: Click into each password field. If your browser's password manager pops up offering a saved list or suggesting a "strong password," that method failed. If you can type cleanly without browser interference, the method succeeded.

Method 1: Dynamic Type Switch

Starts as text to trick the browser on load, then switches to a password type when interacting.

Method 2: Readonly Toggle

Remains read-only until focused, stopping the browser from parsing it early.

Method 3: The Honeypot Decoy

Gives the browser fake hidden fields to attach its password manager to, leaving the real one alone.

Control Group: Standard Login (Allows Password Saving)

Use this to confirm your browser's password manager is working. It should explicitly prompt you to save or autofill.
